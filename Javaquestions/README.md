# Java Questions Practice

This folder contains a Java program, `JavaQ.java`, that demonstrates several pattern-printing exercises using console input.

## About the program

The application asks the user for multiple integer values and then prints different patterns such as:

- Hollow square
- Number triangle
- Increasing number rows
- Diamond pattern
- Hourglass-style design
- Diagonal star pattern
- Reverse triangle
- Alphabet pattern
- Odd number sequence
- Cross pattern

## How to run

From this folder, run:

```bash
java JavaQ.java
```

You will be prompted to enter values for each pattern. The program prints the design one section at a time.

## File

- `JavaQ.java` — contains the main logic for the pattern exercises

## Notes

This is a simple practice project for learning nested loops, pattern generation, and console-based input/output in Java.
